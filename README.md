# СНК информационных технологий

Сайт студенческого научного кружка информационных технологий. Проект рассказывает о направлениях работы СНК, студенческих проектах и возможностях присоединиться к команде.

## Сайт

**[Открыть опубликованную версию](https://experienceiv.github.io/-/)**

## О проекте

СНК объединяет студентов, которым интересны информационные технологии и их применение в медицине и науке. На сайте представлены:

- основные направления работы кружка;
- проекты в области программирования, искусственного интеллекта и анализа данных;
- медицинские технологии и научная деятельность;
- вступительная анкета для новых участников.

## Технологии

Проект сделан без фреймворков и сборщиков:

- HTML5;

## Локальный запуск

Склонируйте репозиторий и откройте `index.html` в браузере:

```bash
git clone https://github.com/ExperienceIV/-.git
cd -
```

Для запуска через локальный сервер можно использовать Python:

```bash
python -m http.server 8000
```

После этого сайт будет доступен по адресу [http://localhost:8000](http://localhost:8000).

## Публикация

Сайт публикуется через GitHub Pages из ветки `main`. После отправки изменений в репозиторий обновление опубликованной версии может занять несколько минут.
